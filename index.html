Guilds of Hyppos - Necromancer Selection Bug

Bug report
Map version: v1.45c
Video proof
Summary
Class Necromancer
Bug type Selection / command card / spell input bug
Required setup Hero Skeleton / minion Pet Ground item
Main issue After selecting a ground item, then box-selecting Necromancer together with skeletons/minions/pet, the hero appears selected but all hero spells become unusable.
Reproduction steps
  1. Have Necromancer with at least one skeleton/minion active.
  2. Have a pet and an item on the ground nearby.
  3. Click the item on the ground.
  4. Box-select the hero together with skeleton/minion/pet.
  5. The hero becomes the main selected unit in the group tab.
  6. Try casting any Necromancer spell.
Result

Expected: Necromancer should cast spells normally after being box-selected with owned units.

Actual: The hero is selected, but all spells become unusable. Both hotkeys and manual spell clicks fail.

Movement, attack, and normal selection still work.

Ways to reset the bug in-game
  • Single-select the Necromancer hero.
  • Box-select only the hero.
  • Use Tab until selection cycles back to the hero.
  • Wait until skeletons/minions expire.
  • Select another non-item target, then reselect the hero.
Suspected cause

This looks like a command-card or selection-state issue caused by selecting a ground item before box-selecting Necromancer with summons. The game shows the hero as the main selected unit, but the hero spell command card no longer accepts spell orders until the selection state is refreshed.
